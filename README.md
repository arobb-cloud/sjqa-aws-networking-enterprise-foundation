# AWS Networking Enterprise Foundation

This project builds a production-style AWS networking foundation using Terraform.

## Project Goals

- Build a custom AWS VPC
- Design public and private subnet tiers
- Configure routing, security groups, and network controls
- Add VPC Flow Logs for operational visibility
- Document troubleshooting and deployment procedures
- Create GitHub portfolio evidence for Cloud Engineer, DBRE, SRE, and DevOps roles

## Target Roles

- Cloud Engineer
- Cloud Database Engineer
- Database Reliability Engineer
- AWS Solutions Architect
- DevOps Engineer
- Platform Operations Engineer

## Tools Used

- AWS
- Terraform
- AWS CLI
- Git
- GitHub
- VS Code
- Windows 11 PowerShell

## Architecture Summary

This project will create a low-cost AWS networking environment suitable for learning enterprise cloud networking patterns.

Cost control is a priority. NAT Gateway will be avoided unless explicitly added later because NAT Gateway creates hourly and data processing charges.
